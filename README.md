# Startup Manager Releases

Public download location for Startup Manager installers.

- Download the latest `installer.exe` from [Releases](https://github.com/0wwzr/Startup-Manager-Releases/releases).
- The application source code is not published in this repository.
- Releases must be tagged `vX.Y.Z` and contain an asset named `installer.exe` for the auto-update to work.
